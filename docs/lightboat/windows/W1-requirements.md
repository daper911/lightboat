# W1 Windows 产品需求

## 1. 背景与目标

轻舟目前在 Windows 上推荐用户安装第三方客户端（Clash Verge Rev、v2rayN），再复制订阅链接导入。新用户要先搞懂「客户端」「订阅」「导入」这些概念，下载渠道也不稳定（GitHub 在国内经常打不开）。

Windows 版的目标和安卓一致：

1. **装好就能用**：用轻舟账号登录，点一个按钮就连上，不接触「订阅链接」；
2. **在 App 里续费**：套餐、到期、流量一目了然，到期前提醒并直接续费；
3. **品牌统一**：和网站、安卓 App 是同一个「轻舟」，宽屏下也有桌面软件该有的样子。

## 2. 范围

| 做 | 不做（第一版） |
|---|---|

| 安装版（Inno Setup 中文安装程序）+ 免安装压缩包 | 微软应用商店、MSIX |
| 系统代理模式 | 虚拟网卡（TUN）进主界面（保留在「高级」里） |

| | 代码签名（暂不签，见 [W4 §5](W4-build-and-ci.md)） |
| | macOS、Linux |

## 3. 目标用户与使用场景

- 普通用户：日常翻墙浏览、看视频、用 ChatGPT 等，不懂代理原理；
- 典型场景：开机自动连上；合上笔记本再打开自动恢复；在公司网络和家里 Wi-Fi 之间切换；偶尔切换线路；到期前收到提醒后续费。

## 4. 共用功能（与安卓同一份代码）

以 0.4.1 的共用功能为准，完整清单和各平台进度见 [功能对照表](../feature-matrix.md)。Windows 用自己的桌面界面（W3），业务逻辑不重写：

| 功能 | Windows 上的差异 |
|---|---|
| 登录（含滑块验证码）、注册、退出、登录状态恢复 | 无；滑块用鼠标拖动 |
| 自动拉取订阅、一键连接 / 断开 | 连接 = 启动内核 + 设置系统代理；断开 / 退出 = 恢复系统代理 |
| 代理模式：智能分流 / 全局 | 无 |
| 线路选择、连接时测延迟、出口地区 | 无 |
| 套餐卡片：到期时间、剩余流量、今日用量、网速 | 宽屏下并排显示 |
| 购买 / 续费、付款（USDT 二维码；支付宝 / 微信跳浏览器收银台） | 「跳浏览器」= 打开系统默认浏览器 |
| 登录失效处理（只清登录，不断连接） | 无 |
| 我的：账号信息、客服、退出登录 | 加「Windows 设置」一组（§5） |
| 检查更新、导出日志、公告、启动时套餐提醒（0.4.0 起） | 已经是共用功能；导出日志在 Windows 上的保存位置待实测 |

**安卓专属、Windows 不显示的**：分应用代理、VPN 授权说明、后台保活引导。

## 5. Windows 专属功能与优先级

P0 = 第一版必须有；P1 = 第一版尽量有；P2 = 以后。

### 5.1 窗口与托盘

| 功能 | 优先级 | 说明 |
|---|---|---|
| 宽屏桌面布局：左侧导航栏 + 右侧内容区 | P0 | 见 [W3](W3-desktop-ui.md) |
| 记住窗口大小和位置 | P0 | FlClash 已有，沿用 |
| 自定义标题栏（品牌色，含最小化 / 最大化 / 关闭） | P0 | FlClash 已有自绘标题栏，换成轻舟样式 |
| 托盘图标：已连接 / 未连接两种状态 | P0 | 小舟图标；未连接为灰色 |
| 托盘菜单：连接 / 断开、模式、打开主窗口、退出 | P0 | 见 W3 §6 |
| 点关闭按钮 = 缩到托盘，不退出 | P0 | FlClash 的 `minimizeOnExit` 默认已开；第一次缩到托盘时提示一次「轻舟仍在后台运行」 |
| 只允许运行一个：再次打开时把已有窗口调到前面 | P0 | FlClash 的 Windows 启动器已有单实例检查，W0 验证 |
| 高 DPI（100%–200% 缩放）显示清晰 | P0 | Flutter 原生支持，测试覆盖 |
| 跟随系统深色 / 浅色 | P0 | 与安卓一致 |

### 5.2 连接与系统

| 功能 | 优先级 | 说明 |
|---|---|---|
| 系统代理（默认） | P0 | FlClash 的 `systemProxy` 默认开启 |
| 退出、断开、卸载时一定恢复系统代理 | P0 | 用户最怕「卸载后上不了网」 |
| 异常退出后的自愈：下次启动发现系统代理还指着本机端口、内核却没在运行，自动清掉 | P0 | W0 先验证 FlClash 现有行为，缺了就补 |
| 端口被占用时给出明确提示 | P1 | 默认混合端口 7890，和其他 Clash 客户端相同；被占用时提示「端口被其他代理软件占用，请先退出它」，可在设置里改端口 |
| 开机自启（默认关） | P1 | FlClash 的 `autoLaunch`；放在「我的 → Windows 设置」 |
| 开机自启时不弹窗口、直接缩在托盘 | P1 | FlClash 的 `silentLaunch` |
| 启动后自动连接（默认关） | P1 | FlClash 的 `autoRun` |
| 睡眠唤醒、切换网络后自动恢复 | P0 | 测试覆盖（W5） |
| 虚拟网卡（TUN）模式 | P2 | 给不认系统代理的软件（游戏、部分命令行工具）用；需要后台服务（安装时已装），第一版只在「高级」里 |
| UWP 应用回环（让商店应用走代理） | P2 | FlClash 自带 `EnableLoopback.exe`，放「高级」 |

### 5.3 更新、日志与卸载

| 功能 | 优先级 | 说明 |
|---|---|---|
| 检查更新：读取 `latest.json` 的 windows 段，提示并下载新安装包 | ✅ 0.4.0 | 共用功能；安装包放在 R2（05 §4），点「下载」用浏览器下载 |
| 导出日志（打码 token、密码、订阅地址） | ✅ 0.4.0 | 共用功能；Windows 上的保存位置待实测 |
| 卸载干净：停掉内核与后台服务、恢复系统代理、删除开机自启项 | P0 | Inno Setup 卸载脚本里 FlClash 已有部分，W1 补齐并测试 |
| 卸载时询问是否保留登录与设置 | P2 | |

### 5.4 需要隐藏的 FlClash 桌面功能

和安卓一样，FlClash 原版界面只能从「我的 → 关于」连点 7 次进入「高级」。另外，桌面版特有的这些在轻舟界面里不出现：配置文件管理、规则 / 连接 / 日志页、全局快捷键、WebDAV 备份、主题与语言设置、FlClash 自身的更新检查（GitHub）。

## 6. 非功能要求

| 项目 | 要求 |
|---|---|
| 安装 | 中文安装界面；安装需要一次管理员确认（后台服务需要，见 W2 §4.3）；默认装到 `Program Files\Lightboat` |
| 启动 | 冷启动到可点「连接」不超过 3 秒（普通笔记本，W5 实测记录） |
| 资源 | 空闲时 CPU 接近 0；内存以 FlClash 原版为基准，不明显增加 |
| 隐私 | 不集成任何统计、崩溃上报、广告 SDK；不收集设备信息（与安卓一致） |
| 存储 | 登录凭据（JWT、订阅 token）用 `flutter_secure_storage` 的 Windows 实现加密保存（DPAPI / 凭据管理器，以插件版本的实现为准，W0 确认），不明文落盘 |
| 语言 | 简体中文；英文系统也显示中文（与安卓一致） |
| 兼容 | 与已安装的 Clash Verge Rev、v2rayN 等共存：不抢对方的系统代理设置；同时开启时以最后点「连接」的为准，并在断开时只恢复自己改过的设置 |

## 7. 不做的事

- 不在 Windows 上做「节点订阅链接」「导入配置」等面向高级用户的入口（保留在「高级」）；
- 不做局域网共享代理开关（默认关闭 `allow-lan`，避免被局域网其他设备滥用）；
- 不做浏览器插件、命令行版本。
