# W3 Windows 宽屏界面

**方向（运营方 2026-10-05 决定）**：Windows 用自己的桌面界面，不是把手机页面拉宽或重新摆放；视觉走轻舟品牌风格（方案 A），不用 Windows 11 原生（Fluent）风格；首页、线路、购买、我的**四页全部按桌面习惯重新设计**。页面代码在 `lib/lightboat/desktop/`，只调用共用逻辑（`lib/lightboat/logic/` 等）和 `widgets/` 里的小组件，不引用 `mobile/`（W2 §3）。

品牌色、字体、Logo、文案语气与安卓相同，见 [08-brand-and-ui.md](../08-brand-and-ui.md)。本文只写桌面布局。风格参考：轻舟网站控制台的左侧导航（宣纸底、江青选中态、印章 Logo），以及运营方喜欢的 bark 侧边栏（分组标题 12 px、导航项 15 px、行高 44 px、选中项浅色底 + 主色字 + 加粗）。

## 1. 窗口

| 项目 | 值 |
|---|---|
| 默认尺寸 | 1080 × 720（首次启动居中；之后记住上次的大小和位置） |
| 最小尺寸 | 880 × 600（窄于此侧边栏会挤压内容；FlClash 原来的 380×400 对宽屏布局太小） |
| 标题栏 | 自绘，高 40 px；左侧印章 Logo 16 px + 「轻舟」；右侧最小化 / 最大化 / 关闭；背景与侧边栏同色，没有分隔线 |
| 关闭按钮 | 缩到托盘（第一次时弹出提示，见 §7） |

## 2. 整体布局

```
┌──────────────────────────────────────────────────────────────────┐
│ ◉ 轻舟                                              ─   ☐   ✕ │ 标题栏 40px
├────────────────┬─────────────────────────────────────────────────┤
│                │                                                 │
│  控制台         │   首页                                          │
│ ▌⌂ 首页        │   ┌───────────────────────┐ ┌─────────────────┐ │
│  ⇄ 线路        │   │                       │ │ 标准套餐  使用中  │ │
│  ⊕ 购买套餐     │   │      ( 连 接 )         │ │ 剩余 86.40 GB    │ │
│                │   │   已连接 · 香港 HK1     │ │ ▓▓▓▓▓▓▓░░  86%   │ │
│  账户          │   │   智能分流 ◉  全局 ○     │ │ 今日 1.20 GB     │ │
│  ☺ 我的        │   │   ↑ 120 KB/s ↓ 2.1 MB/s │ │ 2026-11-04 到期  │ │
│                │   └───────────────────────┘ │ [续费]           │ │
│                │   ┌─────────────────────────┴─────────────────┐ │
│                │   │ 线路   香港 HK1 · Reality  42 ms   [更换]  │ │
│                │   └───────────────────────────────────────────┘ │
│ ───────────    │                                                 │
│ 轻舟已过万重山  │                                                 │
│ v0.4.0         │                                                 │
└────────────────┴─────────────────────────────────────────────────┘
   侧边栏 224px                       内容区（最大宽度 960px，居中）
```

- **侧边栏**宽 224 px，宣纸底（`--qz-paper` 同色，Flutter 里用 `LbColors.paper`），和内容区之间是 1 px 细线（`rule`）；
- 分组标题「控制台」「账户」：12 px，次要文字色；
- 导航项：图标 18 px + 文字 15 px，行高 44 px，圆角 8 px；悬停浅底；**选中**：浅江青底 + 江青文字 + 加粗；
- 底部：一条细线，下面是标题衬线字体「轻舟已过万重山」（`LightboatSerif`）和版本号（12 px，次要色）；
- 内容区：页面标题 22 px（标题衬线体只用于品牌字样，页面标题用常规字体加粗）；内容最大宽度 960 px 居中，窗口很宽时两侧留白，不拉伸卡片。

## 3. 未登录：登录 / 注册

不显示侧边栏。整个窗口宣纸底，中央一张 400 px 宽的卡片：

```
            ◉
          轻 舟
     两岸猿声啼不住，轻舟已过万重山

   ┌──────────────────────────────┐
   │ 邮箱                          │
   │ 密码                     👁   │
   │ [          登 录           ]  │
   │ 忘记密码          注册新账号    │
   └──────────────────────────────┘
```

- 滑块验证码在卡片上方以对话框弹出，鼠标拖动；与安卓共用 `captcha.dart`；
- 回车键提交；Tab 键在输入框之间切换（桌面必须支持键盘操作）。

## 4. 已登录：各页面

| 页面 | 内容（与安卓共用的组件） | 桌面差异 |
|---|---|---|
| 首页 | 连接按钮与状态、代理模式、网速、套餐卡片、当前线路 | 两栏：左边连接区，右边套餐卡片；下方线路条 |
| 线路 | 线路列表、延迟、测速 | 表格式列表，一行一条；双击切换 |
| 购买套餐 | 套餐、时长、付款方式、优惠码 | 套餐卡片横排（2–3 列）；付款弹出对话框，USDT 显示二维码，支付宝 / 微信打开系统浏览器 |
| 我的 | 账号、套餐（切换套餐、刷新、订单）、帮助（公告、教程、客服、导出日志）、关于（检查更新、版本、隐藏的高级入口）、退出登录（与安卓 0.4.1 的四组一致） | 加「Windows 设置」组：开机自启、开机时不显示窗口、启动后自动连接、关闭窗口时缩到托盘；公告用对话框或右侧详情，不推入新页面 |

安卓专属的「分应用代理」「后台保活」「VPN 授权说明」不出现。

## 5. 连接按钮的状态

与安卓一致（未连接 / 连接中 / 已连接 / 失败可重试），桌面上按钮直径 160 px。已连接时按钮下方显示「已连接 · 出口地区」，失败时显示原因和「重试」。

## 6. 托盘

| 状态 | 图标 |
|---|---|
| 未连接 | 灰色小舟 |
| 已连接 | 江青色小舟（暗色任务栏上用浅一档的江青） |

左键单击：打开 / 隐藏主窗口。右键菜单：

```
✓ 已连接 · 香港 HK1          （不可点，只显示状态）
─────────────
  断开 / 连接
  模式  ▸  智能分流 ✓ / 全局
─────────────
  打开轻舟
  退出
```

## 7. 文案

| 场景 | 文案 |
|---|---|
| 第一次点关闭 | 「轻舟仍在后台运行，可从任务栏右下角的小舟图标打开或退出。」[知道了] |
| 端口被占用 | 「本机端口 7890 被其他代理软件占用。请先退出它，或在 我的 → Windows 设置 里更换端口。」 |
| 退出确认（已连接时从托盘退出） | 不弹确认，直接断开并退出；系统代理会恢复 |
| 系统代理被其他软件改掉 | 「系统代理已被其他软件修改，轻舟的连接可能不生效。」[重新设置] |

## 8. 键盘与无障碍

- 所有按钮可用 Tab 聚焦，焦点环 2 px 江青色，立即显示；
- 侧边栏支持上下方向键；
- 文字对比度不低于 4.5:1（深色模式同样）。
