# W5 Windows 测试

Windows 版只能在真机上测：开发服务器是 Linux，云端只负责编译。测试由运营方在自己的 Windows 电脑上进行，AI 负责告诉他下载哪个文件、测哪几项，并根据截图和日志排查。

## 1. 运营方：怎么拿到安装包

1. 浏览器打开 `https://github.com/daper911/lightboat/actions`，并登录 GitHub（不登录下载不了）；
2. 左侧点 **lightboat-windows**，点最上面一条（AI 会把链接直接发给你；Windows 里程碑期间看分支名为 `windows` 的那条）；
3. 等它显示绿色对勾；页面拉到最底部 **Artifacts**，点 `lightboat-windows-…` 下载（一个 zip）；
4. 解压后有两个文件：
   - `…-setup.exe`：安装版，**平时测这个**；
   - `….zip`：免安装版，只在 AI 要求时测。

## 2. 运营方：安装与放行

1. 双击 `…-setup.exe`；
2. 出现蓝色窗口「Windows 已保护你的电脑」：点 **更多信息** → **仍要运行**（我们还没有签名，见 W4 §5）；
3. 出现「是否允许此应用对你的设备进行更改」：点 **是**（安装后台服务需要）；
4. 安装界面是中文，一路「下一步」即可；
5. 如果杀毒软件提示风险：选择「允许」或「信任」；被隔离了就从隔离区恢复并添加排除项。把提示截图发给 AI，正式版前要提交误报申诉；
6. 如果提示「智能应用控制阻止了……」：**先不要关闭智能应用控制**（关闭后无法再打开），截图发给 AI。这说明你的电脑开着智能应用控制，是我们签名之前必须解决的情况。

升级测试版：直接运行新安装包覆盖安装，不用先卸载。

## 3. 测试环境

| 优先级 | 环境 |
|---|---|
| 必测 | 运营方日常用的 Windows 电脑（记下版本：设置 → 系统 → 系统信息） |
| 尽量 | 另一个版本：Windows 10 22H2 与 Windows 11 24H2 各一台（可以借，或在 Windows 电脑上开虚拟机） |
| 尽量 | 屏幕缩放 150% 或以上的笔记本 |
| 尽量 | 装着其他代理软件（Clash Verge Rev / v2rayN）的电脑，测共存 |
| 以后 | ARM 笔记本（如骁龙 X 系列） |

## 4. 回归清单

编号供 AI 在每个里程碑引用（「这次测 W-C1～C6」）。每项记录：通过 / 不通过 + 截图。

### 安装与启动（W-I）

| 编号 | 用例 | 预期 |
|---|---|---|
| W-I1 | 全新安装 | 中文安装界面；开始菜单和桌面有「轻舟」 |
| W-I2 | 首次启动 | 3 秒内出现登录页；窗口居中，1080×720 |
| W-I3 | 已开着轻舟时再双击图标 | 不会开第二个，已有窗口被调到前面 |
| W-I4 | 覆盖安装新版本 | 登录状态和设置都还在 |
| W-I5 | 卸载 | 程序、开始菜单项、开机自启项都删除；**系统代理恢复为关闭**；之后浏览器能正常上网 |

### 账号（W-A）

| 编号 | 用例 | 预期 |
|---|---|---|
| W-A1 | 邮箱 + 密码登录 | 进入首页；回车键能提交 |
| W-A2 | 连续输错 3 次密码 | 弹出滑块，鼠标拖动能通过 |
| W-A3 | 注册新账号（含邮箱验证码与滑块） | 注册后自动登录 |
| W-A4 | 退出登录再登录 | 正常 |
| W-A5 | 关掉程序再打开 | 不用重新登录 |

### 连接（W-C）

| 编号 | 用例 | 预期 |
|---|---|---|
| W-C1 | 点「连接」 | 几秒内显示已连接；「设置 → 网络和 Internet → 代理」里「使用代理服务器」变为开启，地址 127.0.0.1 |
| W-C2 | 浏览器打开 google.com、youtube.com | 能打开 |
| W-C3 | 智能分流下打开 baidu.com、bilibili.com | 正常且速度不受影响（走直连） |
| W-C4 | 切换全局 / 智能分流 | 立即生效 |
| W-C5 | 更换线路 | 立即生效，显示新延迟 |
| W-C6 | 点「断开」 | 系统代理恢复为关闭；托盘图标变灰 |
| W-C7 | 已连接时从托盘「退出」 | 系统代理恢复；浏览器直连正常 |
| W-C8 | 已连接时在任务管理器里强制结束轻舟，再打开 | 打开后不会出现「整机上不了网」；系统代理被自动恢复（或提示并一键恢复） |
| W-C9 | 已连接时让电脑睡眠 10 分钟再唤醒 | 自动恢复，网页能打开 |
| W-C10 | 已连接时切换 Wi-Fi / 拔插网线 | 自动恢复 |
| W-C11 | 同时装着 Clash Verge Rev：先开它再开轻舟连接，再断开轻舟 | 不出错；断开后不把对方的设置搞乱（记录实际表现） |
| W-C12 | 先开着另一个占用 7890 端口的代理软件（如 Clash Verge 改端口为 7890），再在轻舟点「连接」 | 不连接，按钮下方提示「本机端口 7890 已被其他程序占用……」；退出那个软件后再点能连上 |

### 窗口与托盘（W-W）

| 编号 | 用例 | 预期 |
|---|---|---|
| W-W1 | 点关闭按钮 | 窗口隐藏，托盘还在；第一次有提示 |
| W-W2 | 左键单击托盘图标 | 打开 / 隐藏主窗口 |
| W-W3 | 托盘右键菜单 | 能连接 / 断开、切换模式、退出 |
| W-W4 | 改窗口大小和位置，重启程序 | 大小和位置保持 |
| W-W5 | 屏幕缩放 150% / 200% | 文字和图标清晰，布局不乱 |
| W-W6 | 系统切换深色 / 浅色 | 跟随切换 |
| W-W7 | 托盘右键「模式」切到全局，再切回智能分流 | 首页的模式同步变化；托盘图标在连接时变江青色、断开后变灰 |
| W-W8 | 窗口拉到最小（880×600）和最大化 | 首页两栏、线路表格、购买页、我的页都不重叠、不截断 |

### Windows 设置（W-S）

| 编号 | 用例 | 预期 |
|---|---|---|
| W-S1 | 打开「开机自启」，重启电脑 | 自动启动 |
| W-S2 | 同时打开「开机时不显示窗口」 | 只在托盘出现 |
| W-S3 | 同时打开「启动后自动连接」 | 开机后自动连上 |

### 购买与套餐（W-P）

| 编号 | 用例 | 预期 |
|---|---|---|
| W-P1 | 首页套餐信息 | 与网站一致：到期时间、剩余流量、今日用量 |
| W-P2 | 购买 / 续费选支付宝 | 打开系统默认浏览器的收银台；付款后回到轻舟，套餐自动刷新 |
| W-P3 | 选 USDT | 显示二维码和地址 |

## 5. 问题反馈

发给 AI 的信息越全越快：截图、发生时间、做了什么操作、Windows 版本；能导出日志时附上日志（日志已打码，可以放心发）。
