# 01 产品需求

> 版本：2026-10-04 初稿。依据：主项目远期规划 `vpn/docs/roadmap/android-client.md` 以及与运营方的讨论。

## 1. 背景

轻舟目前通过网站提供服务。安卓用户的使用路径是：注册并购买 → 在网站「连接设备」下载第三方客户端（推荐 FlClash，备选 v2rayNG、Hiddify）→ 点「导入到 Clash」→ 在客户端里连接。

这条路径能用，但对新手不够友好：

- 要先理解什么是「客户端」「订阅」；
- 要从第三方渠道下载 App（GitHub 在国内经常打不开）；
- 套餐到期、流量用尽时，第三方客户端不会提示续费。

自有 App 的价值在于：少一次跳转和一个第三方 App；品牌感更强；能在 App 内提示到期、流量和公告，并引导续费。

## 2. 目标

1. **傻瓜化**：安装 → 登录 → 点一下 → 连上。全程不出现「订阅链接」「协议」「节点配置」这类词。
2. **可靠**：连接成功率、后台保活不低于原版 FlClash。
3. **可运营**：显示套餐状态，到期、流量用尽能提醒并引导续费，能推送公告。
4. **可维护**：轻舟自己的代码与上游 FlClash 隔离，能持续合并上游的修复和新内核。

## 3. 范围

| 平台 | 结论 |
|---|---|
| Android | **本项目** |
| Windows / macOS / Linux | 第二期。FlClash 本身支持这三个平台，同一套 Flutter 代码，增量约 1–2 周 |
| iOS | **不做**。需要 Apple 开发者账号与 Network Extension 权限；VPN 类 App 审核严格，且不能上架中国区；绕过 App Store 分发违反苹果规则，证书随时可能被吊销。iOS 继续使用小火箭，配合网站上的「导入到小火箭」 |

分发方式：**只在官网提供 APK 下载**。国内应用商店不可能上架 VPN 类 App；Google Play 需要企业开发者账号和 VPN 专项审核，而且大陆用户访问不了。

## 4. 目标用户

- 中国大陆用户，大多数不懂技术；
- 主流机型：小米 / 红米（HyperOS）、华为 / 荣耀（HarmonyOS / MagicOS）、OPPO / 一加（ColorOS）、vivo / iQOO（OriginOS）；
- Android 7.0（API 24）及以上（与 FlClash 的 minSdk 一致）；
- 绝大多数是 arm64-v8a 设备。

## 5. 核心流程

```
首次打开
  └─ 登录页：邮箱 + 密码
       ├─ 没有账号 → 「去官网注册」（浏览器打开 https://ssr.cnbetx.com/#/auth）
       ├─ 忘记密码 → 「去官网找回」（同上）
       └─ 连续输错 3 次 → 弹出滑块验证码 → 通过后继续登录
  └─ 登录成功 → 自动拉取订阅（配置）→ 进入首页
首页
  ├─ 套餐卡片：套餐名、到期日期（剩余天数）、已用 / 总流量（进度条）
  ├─ 大按钮「连接」→ 第一次使用时系统弹出 VPN 授权 → 连上
  │     连接中：显示「已连接」、当前线路（默认「自动选择最快」）、延迟
  ├─ 线路：默认自动（url-test），点开可以手动选具体节点
  └─ 提示条：套餐 7 天内到期 / 已到期 / 流量用尽 → 「去续费」
我的
  ├─ 账号邮箱、套餐详情、续费（打开官网购买页）
  ├─ 使用教程、联系客服（工单页 / 客服邮箱）
  ├─ 设置：开机自动连接、分应用代理（高级）、路由模式（规则 / 全局，高级）
  ├─ 检查更新、导出日志、关于（版本号、开源许可、服务条款、隐私政策）
  └─ 退出登录
```

每次启动、以及在后台每 6 小时，自动更新订阅和套餐信息。订阅更新失败时继续使用缓存的配置，不影响已经建立的连接。

## 6. 功能清单与优先级

P0 = 第一版必须有；P1 = 第一版最好有；P2 = 以后再说。

### 6.1 账号

| 功能 | 优先级 | 说明 |
|---|---|---|
| 邮箱密码登录 | P0 | `POST /v1/auth/login`，见 [02](02-panel-integration.md) |
| 滑块验证码 | P0 | 面板返回 110001 时弹出；登录失败 3 次后必然出现，没有它就登不进去 |
| 登录状态持久化 | P0 | JWT 与订阅 token 存在加密存储中；App 重启不用重新登录 |
| 登录失效处理 | P0 | JWT 7 天过期（错误码 40002–40005）。**订阅 token 不受影响，连接照常工作**，只在需要账号接口时提示重新登录，见 [02 §4](02-panel-integration.md) |
| 退出登录 | P0 | 断开连接，清除 token、订阅缓存、配置文件 |
| 注册 / 找回密码 | P0 | 第一版不做原生页面，用浏览器打开官网 |
| 原生注册（含邮箱验证码 + 滑块） | P2 | |

### 6.2 连接

| 功能 | 优先级 | 说明 |
|---|---|---|
| 一键连接 / 断开 | P0 | 走 FlClash 原有的 Android VpnService（TUN） |
| 自动选择最快线路 | P0 | 订阅里自带 `🌏 Auto`（url-test）分组；首页默认选它 |
| 手动选择节点 | P0 | 列出订阅中的节点，显示延迟，可以测速 |
| 连接状态通知 | P0 | 前台服务通知（Android 要求），显示已连接时长与流量；沿用 FlClash |
| 快捷开关（下拉通知栏磁贴） | P1 | FlClash 已有，保留并改成品牌名 |
| 开机自动连接 | P1 | FlClash 已有，放进设置 |
| 路由模式：规则 / 全局 / 直连 | P1 | 默认「规则」，放进「高级」 |
| 分应用代理 | P1 | FlClash 已有，放进「高级」 |
| 后台保活引导 | P1 | 首次连接成功后，按机型引导用户设置电池优化白名单与自启动，见 [06](06-testing.md) |

### 6.3 套餐与运营

| 功能 | 优先级 | 说明 |
|---|---|---|
| 套餐名、到期时间、流量 | P0 | 来自 `GET /v1/public/user/subscribe`；登录失效时退而使用订阅响应头 `subscription-userinfo` |
| 多个套餐时的选择 | P0 | 用户可能有多份订阅：默认选第一个有效的，允许切换 |
| 到期、流量提醒 | P0 | 首页提示条；到期前 3 天与当天各发一条本地通知（P1） |
| 续费 / 购买 | P0 | 浏览器打开 `https://ssr.cnbetx.com/#/subscribe`，用户在网页登录后付款 |
| App 内 WebView 付款 | P2 | 需要把登录态注入 WebView，第一版不做 |
| 公告 | P1 | `GET /v1/public/announcement/list`；`popup=true` 的公告启动时弹出一次 |
| 使用教程、联系客服 | P1 | 打开官网教程页 / 工单页；显示客服邮箱 support@mail.cnbetx.com |
| 邀请返利 | P2 | |

### 6.4 应用

| 功能 | 优先级 | 说明 |
|---|---|---|
| 检查更新 | P0 | 读取官网上的 `latest.json`，有新版本时提示下载并安装，见 [05](05-build-and-release.md) |
| 导出日志 | P0 | 没有模拟器、多数用户不会用 adb，这是排查问题的主要手段（保存或分享成文件） |
| 关于页 | P0 | 版本号、开源许可（GPL-3.0，附源码地址）、服务条款、隐私政策 |
| 中文界面 | P0 | 简体中文为主 |
| 英文界面 | P1 | FlClash 自带多语言框架，补充轻舟新增的文案即可 |
| 深色模式 | P1 | 跟随系统；配色见 [08](08-brand-and-ui.md) |
| 域名容灾 | P0（设计）/ P1（远程更新） | 内置多个面板地址按顺序尝试；远程更新地址列表见 [03 §5](03-architecture.md) |

### 6.5 需要隐藏或删除的 FlClash 功能

FlClash 面向技术用户，功能很多。第一版**默认界面只保留上面列出的功能**，其余的处理方式：

| FlClash 功能 | 处理 |
|---|---|
| 多配置文件管理、手动添加订阅、配置编辑器、覆写脚本 | 隐藏。用户只有「轻舟账号」这一个配置来源 |
| 连接 / 请求 / DNS 实时查看、日志页 | 隐藏，只保留「导出日志」 |
| WebDAV 备份 | 删除 |
| Firebase Analytics / Crashlytics | **必须删除**：Google 服务在国内不可用；我们也不收集用户数据（隐私政策承诺） |
| 桌面端相关代码 | 保留不动（第二期要用），只是不在 Android 构建中启用 |

是否保留一个「开发者模式」入口（比如连点版本号 7 次）来打开 FlClash 原有的完整界面，便于排查问题，由开发阶段决定。

## 7. 非功能要求

| 类别 | 要求 |
|---|---|
| 性能 | 冷启动到首页 ≤ 2 秒（已登录、有缓存）；点击连接到「已连接」≤ 3 秒（已授权 VPN） |
| 稳定 | 后台连续运行 24 小时不断线（在完成保活设置的前提下）；网络切换（Wi-Fi ↔ 4G/5G）后 10 秒内自动恢复 |
| 耗电 | 不高于原版 FlClash；不做常驻轮询，订阅更新用 WorkManager 之类的系统调度 |
| 隐私 | 不集成任何统计或崩溃上报 SDK；日志只存在本机，用户主动导出才离开设备；导出前去掉 token、密码、订阅地址 |
| 安全 | JWT、订阅 token 存在 Android Keystore 支持的加密存储中；订阅配置（含节点密码）只放在 App 私有目录；所有接口走 HTTPS |
| 抗封锁 | 面板域名被封时，App 能通过备用地址继续登录、更新订阅（见 [03 §5](03-architecture.md)） |
| 兼容 | Android 7.0+；arm64-v8a 必须支持，armeabi-v7a 建议支持；国产系统的保活适配见 [06](06-testing.md) |
| 体积 | 单 ABI 的 APK ≤ 40 MB（参考 FlClash arm64 包的大小） |
| 开源 | 发布 APK 时公开对应源码（GPL-3.0），关于页给出源码地址 |

## 8. 不做的事

- iOS；
- 国内应用商店、Google Play 上架；
- App 内直接调用支付宝 / 微信支付 SDK（付款走官网）；
- 用户行为统计、广告；
- 自建节点协议或修改 mihomo 内核。

## 9. 与主项目规划的关系（启动条件）

主项目的远期规划曾列出三个「启动条件」，当前状态如下：

| 条件 | 状态（2026-10-04） |
|---|---|
| 面板域名抗封锁：面板走 CDN、备用域名就绪 | 部分完成：订阅（sub.cnbetx.com）和节点（hk1.cnbetx.com）已经与面板域名分开；面板没有接 CDN，也没有备用域名 |
| 节点不少于几个地区 | **未满足**：目前只有香港 HK1 一个节点（Reality + Hysteria2） |
| 网站的客户端下载、试用上线，付费用户跑起来 | 进行中 |

运营方决定**先搭环境、做出第一版**。原型和内测可以先进行，**正式对外发布 APK 前**要再看一次这张表，至少保证有备用面板地址，最好多于一个节点。
