# 08 品牌与界面

> 与网站保持一致。网站的设计系统见主项目 `vpn/frontend/apps/user/design.md` 和 `src/styles/tokens.css`。

## 1. 品牌

- 名称：**轻舟**，英文 **Lightboat**。出自李白《早发白帝城》「两岸猿声啼不住，轻舟已过万重山」——轻快地越过重重阻隔，从容、不费力。
- 气质：编辑感、山水（水墨）意境；安静、克制，不用渐变、霓虹、科技感插画。
- 文案原则：说人话，不用术语。用「连接」，不说「启动代理」；用「线路」，不说「节点 / 出站」；用「套餐」，不说「订阅」。

## 2. Logo 与图标

- 主 Logo：朱砂色圆角方形印章，里面是一叶小舟和水纹。源文件：`vpn/frontend/apps/user/public/favicon.svg`（64×64 矢量）；位图：`pwa-512x512.png`、`pwa-maskable-512x512.png`（自适应图标用 maskable 版本，主体在安全区内）。
- 安卓启动器图标：自适应图标，前景是白色的舟和水纹线条，背景是朱砂色 `#C5372F`；单色图标（Android 13 主题图标）用同样的线条。
- 通知栏小图标：白色单色的舟形线条，透明背景。

## 3. 配色

由网站的 oklch 设计变量换算成 sRGB 十六进制（2026-10-04）：

| 用途 | 变量 | 浅色（宣纸） | 深色（夜航） |
|---|---|---|---|
| 页面背景 | paper | `#FAF6EE` | `#08131A` |
| 正文 / 标题 | ink | `#14212A` | `#ECE7DE` |
| 分割线、边框 | rule | `#DCD7CC` | `#26323A` |
| 主色：按钮、链接、已连接状态 | accent（江青） | `#006C6C` | `#65BCB7` |
| 主色上的文字 | accent-ink | `#FBF8F1` | `#061118` |
| 主色浅底（12–14% 透明度） | accent-soft | `#006C6C` @12% | `#65BCB7` @14% |
| 印章、警示（到期、流量用尽、错误） | seal（朱砂） | `#C5372F` | `#DD574B` |
| 远山、次要底色 | mist | `#BFD6D7` | `#253C42` |
| 焦点环 | focus | `#007C7C` | `#60CCC5` |

规则：

- 主色在任何一屏的面积不超过约 5%：主按钮、链接、已连接的状态；
- 朱砂色只用于 Logo，以及需要用户注意的状态（到期、流量用尽、错误）；
- 关闭 Material You 动态取色，始终使用品牌色；
- 深色模式跟随系统。

## 4. 字体

- 标题：宋体风格的衬线体（网站用的是 Noto Serif SC Bold 的子集「轻舟宋」）。App 里只有「轻舟」品牌字和少数大标题用衬线体，可以打包一个只含所需汉字的子集字体（几十 KB），其余回退到系统字体；
- 正文：系统默认无衬线字体（国产系统各自的中文字体）；
- 数字（流量、剩余天数、延迟）用等宽数字（`FontFeature.tabularFigures()`）。

## 5. 圆角与形状

沿用 FlClash 的超椭圆圆角体系（`lib/common/shape.dart` 的 `AppShape` / `AppRadius`，有测试强制检查）。卡片用中等圆角，主按钮用胶囊形。

## 7. 主要文案（简体中文）

| 场景 | 文案 |
|---|---|
| 登录按钮 | 登录 |
| 登录失败 | 密码错误 / 账号不存在 / 账号已被停用，请联系客服 / 操作太频繁，请稍后再试 |
| 滑块 | 标题「安全验证」；提示「拖动下方滑块，把拼图移到缺口处。」；答错「没对准，换一张再试试。」 |
| 连接按钮下方 | 未连接 / 正在连接… / 已连接 02:31 / 连接失败：<原因> |
| 线路 | 自动选择最快 |
| 套餐状态 | 有效 / 已过期 / 流量已用完 |
| 提醒 | 套餐 3 天后到期 / 套餐已过期，续费后即可继续使用 / 本周期流量已用完 |
| 续费按钮 | 去续费 |
| VPN 授权说明 | 轻舟需要创建一个本地 VPN 才能为你加密连接，不会读取你的数据。 |
| 登录失效 | 登录已过期，请重新登录（连接不受影响） |
| 订阅更新失败 | 暂时无法更新线路，已使用上次的配置 |
| 新版本 | 发现新版本 1.1.0 · 立即更新 |
