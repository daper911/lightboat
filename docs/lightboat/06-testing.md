# 06 测试

> 本文是安卓的测试。Windows 测试（下载、安装、放行、回归清单）见 [windows/W5](windows/W5-testing.md)。

## 1. 测试方式

构建机没有 KVM，**跑不了模拟器**，所有功能验证都在真机上进行：

| 方式 | 适用 |
|---|---|
| 单元测试 / 组件测试（`flutter test`，在容器里跑） | API 客户端、错误码映射、订阅响应头解析、套餐状态判断、滑块坐标换算、地址列表签名校验 |
| 真机手动测试 | 连接、VPN 授权、后台保活、网络切换、安装与升级 |
| 日志 | App 内「导出日志」；有电脑时用 `adb logcat` |

## 2. 机型矩阵

至少覆盖下面的前三行。国产系统在「后台杀进程」「拦截 VPN」上各有不同：

| 品牌 / 系统 | 重点检查 |
|---|---|
| 小米 / 红米（HyperOS） | 省电策略「无限制」、自启动、锁定后台；「安全守护」对未知来源应用的拦截 |
| 华为 / 荣耀（HarmonyOS 4 及以下 / MagicOS） | 「应用启动管理」改为手动并全部打开；纯净模式拦截安装；HarmonyOS NEXT 不能装 APK，不在支持范围内 |
| OPPO / 一加 / realme（ColorOS） | 「允许后台运行」、「自启动」；电池「应用耗电管理」 |
| vivo / iQOO（OriginOS） | 「后台高耗电」、「自启动」 |
| 原生 / 接近原生（Pixel、三星） | 作为基准 |

每种机型确认后，把保活设置的具体路径写进 App 的「保活引导」和网站教程。

## 3. 回归用例（每个版本都要过）

### 安装与升级

- [ ] 全新安装：允许未知来源后可以装上，打开后进入登录页
- [ ] 覆盖升级：从上一版直接安装新版，登录状态、设置都还在
- [ ] 卸载后重装：从登录页重新开始，没有残留

### 账号

- [ ] 正确的邮箱和密码能登录，进入首页并显示套餐
- [ ] 密码错误：提示「密码错误」；邮箱不存在：提示「账号不存在」
- [ ] 连续输错 3 次后再登录：弹出滑块；拖对了能登录；拖错了换图；关闭滑块时不发请求
- [ ] 登录过于频繁被限流（HTTP 429）时，提示「操作太频繁」，不自动重试
- [ ] 「去官网注册」「忘记密码」用浏览器打开正确的页面
- [ ] 退出登录：断开连接，清除数据，回到登录页
- [ ] JWT 过期（可以在服务器上让 token 失效来模拟）：**连接不断开**，订阅照常更新；打开「我的」时提示重新登录

### 订阅与套餐

- [ ] 登录后自动拉取订阅，节点列表里出现 `香港 HK1 · Reality`、`香港 HK1 · Hysteria2`
- [ ] 订阅请求的 UA 包含 `Clash`（拿到的是 YAML，不是 base64）
- [ ] 套餐名、到期日期、已用 / 总流量与网站首页显示一致
- [ ] 多份订阅时可以切换
- [ ] 在网站上「更换订阅链接」后，App 能自动拿到新链接（JWT 有效时），或者提示重新登录（JWT 失效时）
- [ ] 断网时打开 App：用缓存的配置和套餐信息，提示「无法更新」
- [ ] 套餐过期 / 流量用尽：首页显示提示条，「去续费」打开购买页
- [ ] 套餐 3 天内到期 / 已过期 / 流量用尽：打开 App 时弹出「套餐提醒」，同一天只弹一次；点「去续费」打开购买页
- [ ] 全新安装后第一次连接：不用等规则下载，几秒内连上（规则集已内置，02 §5）

### 连接

- [ ] 首次连接弹出系统 VPN 授权；拒绝后有说明、可以重新授权
- [ ] 点击连接后 3 秒内显示「已连接」；访问 Google、YouTube 正常，访问国内网站走直连
- [ ] 默认线路是「自动选择最快」；手动切到 Reality 或 Hysteria2 都能正常上网
- [ ] 线路列表里没有「🎯 Direct」（直连）
- [ ] **全局模式**下打开 Google、YouTube 正常（0.3.0 及以前全局实际是直连，见 02 §5）；换线路后全局也跟着换
- [ ] Wi-Fi 与移动数据来回切换，10 秒内自动恢复
- [ ] 锁屏 30 分钟后仍然连接；后台运行 24 小时不断线（已完成保活设置）
- [ ] 通知栏常驻通知、快捷开关可用
- [ ] 开机自动连接（开启时）
- [ ] 断开连接后流量恢复直连，系统 VPN 图标消失

### 其他

- [ ] 公告：「我的 → 公告」能看到列表（置顶在前）；`popup` 公告只弹一次
- [ ] 检查更新：「我的 → 检查更新」在最新版本时提示「已经是最新版本」；R2 上有更高版本时弹窗，点「下载」用浏览器下载安装包（05 §4）
- [ ] 导出日志：「我的 → 导出日志」能保存文件；文件开头有版本、系统、模式、各分组线路；文件里没有 token、密码、订阅地址、完整邮箱
- [ ] 登录失败的提示能区分「连接服务器超时」「找不到服务器地址」「服务器证书校验失败」「网络连接失败」
- [ ] 深色模式显示正常
- [ ] 关于页：版本号、开源许可、源码地址、服务条款、隐私政策都能打开

## 4. 测试账号

在面板上专门建测试账号（例如 `probe-android-*@example.com`），开通内部测试套餐（「内部测试（不出售）」，前台不显示）。不要用真实用户的账号测试。测试账号的创建和清理在主项目里操作，见 `vpn/docs/operations.md`「测试数据」。
